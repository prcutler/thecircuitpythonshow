# The CircuitPython Show

## About The CircuitPython Show
The CircuitPython Show is an independent podcast and created and hosted by Paul Cutler that was started in 2022. In most episodes, Paul interviews someone in the CircuitPython community doing something cool with CircuitPython. It could be they created a new library, a project powered by CircuitPython, or contributed in some way. Most episodes are an interview format, though there are some episodes focused on a specific topic or panel interviews with a number of different guests.

The CircuitPython Show is published bi-weekly when in season. Seasons vary based on the number of interviewees available and as Paul's time permits.
